## Completion rule

Do not mark an intervention “implemented” solely because code was written or a prototype was demonstrated. Implementation requires an accountable operator, fit-for-purpose testing, training/documentation, maintenance and recovery arrangements, an accessible fallback where needed, and explicit acceptance against the stated requirements. Mark outcomes “evaluated” only after collecting and reviewing the planned evidence.
