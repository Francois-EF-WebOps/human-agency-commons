# Cage Fluency Glossary

**Status:** Working vocabulary, version 0.2 research update. These terms organise a proposed framework; they are not all established scientific constructs.

| Term | Working definition | Boundary / caution |
|---|---|---|
| Agent | System that observes, chooses actions, and produces effects toward objectives | Human, organisational, and machine agency differ substantially |
| Constraint system / cage | Rules, incentives, interfaces, institutions, and limits shaping available actions | A constraint may protect, coordinate, or restrict |
| Cage Fluency | Ability to preserve navigation capability while operating inside, through, and where feasible outside evolving constraint systems | Not permission to evade lawful safeguards or treat every constraint as hostile |
| Navigation capability | Ability to orient, decide, act, detect consequential error, and revise course while retaining viable options | Must be operationalised for a specific domain |
| Drift | Accumulation of differences between reality and the agent's projection of reality | A difference is a signal, not automatically a threat |
| Projection / map | Partial representation used to make decisions | Always incomplete; confidence should be calibrated |
| Reconnaissance / scouting | Purposeful observation aimed at a decision-relevant uncertainty | Needs a question, budget, and stopping rule |
| Adaptation | Revising a map, action, resource allocation, skill, or objective in response to evidence | Change without evidence can be churn rather than adaptation |
| Adaptive continuity | Preserving essential function while retaining the ability to change course | Not the same as keeping the original plan unchanged |
| Resource allocation | Deliberate distribution of time, energy, attention, money, trust, health, and tools | Time alone is not the full cost |
| Babar | Archive metaphor for a backlog of observations and unresolved questions awaiting triage | Not a diagnosis; does not certify the accuracy of archived memories |
| Closure | Resolving, retiring, or parking an item with a rationale and reopening condition | Not forgetting or denying |
| Label | Short name for a category | Useful for retrieval; lossy and context-sensitive |
| Observation | What was seen, heard, recorded, or measured | Record source and context where possible |
| Interpretation | Possible explanation of an observation | Must not be presented as direct observation |
| Hypothesis | Explanation that can be compared with alternatives | Needs evidence that could support or weaken it |
| Principle | Reusable rule of thumb with scope and limitations | Not a universal law |
| Adaptation score | Proposed context-specific measure of adaptation | Not a validated universal score |
| Productivity | Conversion of resources into progress toward a defined objective, considering quality and sustainability | Output volume alone can reward waste or harm |
| Control | Action directly available to the agent in the current context | Context can change |
| Influence | Ability to affect an outcome without determining it | Not equivalent to control |
| Uncertainty | Gap in knowledge or predictability relevant to a decision | State it rather than hide it behind confident language |

## Stable operating distinctions

1. **Fact is not interpretation or hypothesis.**
2. **Activity is not necessarily progress.**
3. **Time spent is not the same as value created.**
4. **A pattern is not proof of coordination or intent.**
5. **A remembered event is not independent corroboration of every detail.**
6. **A working model is not a validated theory.**
7. **A useful label is not a complete explanation.**
8. **Closure is not erasure.**
9. **A free public document is not a funded operating model.**
10. **A prototype is not a proven intervention.**


## Related research

The terms in this glossary overlap with established work in cybernetics, viability theory, ecological psychology, resilience engineering, situation awareness, active inference, OODA, cognitive control, and SRE.
